# 网络设备信息采集工具（C 语言版）

双击 `netcollect.exe` 打开图形界面，选择 Excel 模板、输出目录和并发设备数，点击“开始采集”。运行环境为 Windows 10/11 x64；程序本体使用 C 和 Windows 原生 API，无需安装 Python、Excel 或额外运行库。本仓库仅包含 C 语言版本。

当前版本：V0.1，采集任务日志直接保存在所选输出目录；支持在同一份 Excel 中混合配置 SSH 和 Telnet，保留实时运行日志和“打开日志目录”按钮。

## Excel 模板

第一个工作表必须包含 `ip地址`、`用户名`、`密码`、`OS类型` 四列表头。后续工作表名称应与设备的 `OS类型` 完全一致。例如 `Huawei_SW` 对应名为 `Huawei_SW` 的工作表。

| 可选列 | 默认值 | 说明 |
| --- | --- | --- |
| 登录方式 | SSH | `SSH` 或 `TELNET`，不区分大小写；缺少该列或留空均使用 SSH |
| 端口 | SSH 为 22，Telnet 为 23 | 端口留空时按登录方式选择；也可填写 1–65535 的自定义端口 |
| 编码 | auto | `auto`、`utf-8`、`gb18030`、`gbk`、`big5`、`latin1` |
| 超时秒 | 90 | 单条命令总等待时间，1–3600 秒；大配置可适当增加 |

命令工作表优先读取表头为 `命令`、`command` 或 `cmd` 的列；没有这些表头时，从第一列第一条非空内容开始读取。空行和以 `#` 开头的备注不执行，命令按行顺序执行。单元格中的换行命令不接受。

支持 `.xlsx` 和 `.xlsm`，包括共享字符串、富文本字符串、XML 命名空间及稀疏单元格。宏不会执行。不支持旧版 `.xls` 和加密工作簿；请另存为未加密 `.xlsx`。密码和长数字建议设为文本，密码首尾空格会保留。公式仅读取保存的缓存值。

`C版采集模板.xlsx` 中的 `192.0.2.x` 为示例地址，使用前替换为实际设备信息。程序也能读取旧版四列模板。

第一张表新增 H 列“登录方式”，提供 SSH/TELNET 下拉选项，示例包含两台 SSH 和一台 Telnet 设备。命令 Sheet 和 `OS类型` 的匹配方式不变。界面“检查模板”会分别显示 SSH 和 Telnet 设备数量；点击“开始采集”后逐行采用各设备的登录方式，无需在界面切换整个任务的协议。

Telnet 支持 `Username:`、`User name:`、`login:`、`Password:` 以及中文“用户名：”“密码：”等常见提示，支持只要求密码的设备。密码认证设备的“用户名”单元格可以留空；如果设备实际要求用户名而表中未填写，程序会明确报告失败。用户名、密码禁止换行，最多 8192 字节；密码首尾空格仍保留。Telnet 登录等待上限为 15 秒，“超时秒”小于 15 时也作为登录上限。

Telnet 采用 libtelnet 处理 IAC 转义、选项协商、VT100 终端类型及窗口尺寸，兼容分段到达的登录提示和协议数据。输入命令和账号密码按“编码”列转换（`auto` 输入时采用 UTF-8）；GBK/Big5 设备如使用中文账号或命令，应明确指定相应编码。Telnet 的账号密码和内容以明文传输，适用于可信的管理网络。协议不会在 SSH 失败后自动改为 Telnet。

## 输出文件

```text
输出目录/
  SW-Core_192.168.1.1/
    display version.txt
    display interface _ include up.txt
    _session.log
  Router-1_192.168.1.2_2222/
    show version.txt
    _session.log
  H3C-Access_192.168.1.3_23/
    display version.txt
    _session.log
  _summary.csv
  _known_hosts
  collection_20261016_093000_123_1234_2.log
```

设备名取自登录后实际返回的 CLI 提示符，而不是 Excel 的 OS 名称。支持 `<设备名>`、`[设备名]`、`设备名#`、`设备名>`、`设备名(config)#` 和 `用户名@设备名>` 等常见形式。Huawei 提示符中的 `~`、`*` 状态标记会去除。SSH 使用非 22 端口时，目录末尾增加端口号；Telnet 始终增加端口号（包括默认 23），避免同一设备使用两种登录方式采集时互相覆盖。无法识别提示符时会报告失败。汇总 `_summary.csv` 末尾增加“登录方式”列。

命令文本作为文件名：`|` 改为 `_`，中间空格保留。Windows 禁止的文件名字符也会替换；保留名增加前缀，过长名称截断。重复命令、大小写冲突以及替换后重名使用 ` (2)`、` (3)` 等后缀，完整命令到文件名的对应关系保存在 `_session.log`。同目录重复运行时覆盖本次的同名文件，历史多余文件不会自动删除。

文本采用带 BOM 的 UTF-8，便于 Windows 记事本和 Excel 打开。自动编码先严格尝试 UTF-8，再尝试 GB18030；清除常见 ANSI/OSC 控制序列、退格和 NUL 填充。有损转换时记录警告，并在 `.txt.raw` 中保留原始输出字节（Telnet 为去除协议协商和 NVT 处理后的终端数据）。编码无法仅凭字节在所有情况下可靠判断；繁体设备或仍有乱码的设备应在“编码”列明确指定 Big5/GBK 等实际编码。

超时、断线和停止采集会保留已收到的输出，并标注 `INCOMPLETE`，随后停止该设备剩余命令。其他设备继续采集；停止按钮会同时停止整个任务和等待队列。总结果在 `_summary.csv`，失败原因也显示在运行日志中。登录前失败的设备尚未取得设备名，因此记录到汇总、界面日志及任务日志。

## 运行日志与排错

程序每次启动即生成应用日志，开始采集后另生成任务日志，结束或失败后均保留：

| 日志 | 默认位置 | 内容 |
| --- | --- | --- |
| 应用日志 `application_*.log` | EXE 所在目录的 `logs` 子目录 | 启动、退出、模板检查、界面操作及采集事件 |
| 任务日志 `collection_*.log` | 所选输出目录本身，与 `_summary.csv` 同级 | 模板读取、登录方式、TCP/SSH/Telnet 阶段、认证结果、设备名、命令开始和结束、接收字节数、耗时、编码警告、错误及总结果 |
| 设备命令映射 `_session.log` | 设备名与管理地址目录内 | 本设备命令、文件名映射及最终状态 |

任务日志不再创建 `logs` 子目录，轮转后的日志段也保存在输出目录本身。“打开日志目录”会打开界面当前选择的输出目录；未选择有效输出目录时打开应用启动日志目录。之前版本留下的 `logs` 子目录及历史日志会保留，不自动迁移或删除。

程序刚启动、尚未选择输出目录时，应用启动日志仍使用程序目录的 `logs`；该目录不可写时自动改存到 `%LOCALAPPDATA%\NetCollect\logs`。任务日志无法创建时，程序会明确报错并停止启动采集；输出目录错误也会写入应用日志。

应用和任务日志均实时写入，采用带 BOM 的 UTF-8，每行包含毫秒时间、`DEBUG/INFO/WARN/ERROR` 级别以及进程和线程 ID。多设备并发不会交叉写坏同一条日志，任务运行期间即可打开文件查看。错误事件和日志关闭时会刷新文件；每个日志段约 8 MiB，达到上限后按 `_001.log`、`_002.log` 继续保存。每次运行使用独立名称，不覆盖之前的日志；历史日志不会自动删除。

日志不会主动输出登录密码，设备相关日志中的当前登录密码会脱敏为 `[REDACTED]`。不会将设备返回的完整配置内容写入运行日志，采集内容仍单独保存在命令文本文件中。查看失败原因可搜索 `ERROR`、`COMMAND_FAILED`、`DEVICE_END` 或 `RUN_END`；模板错误和登录失败也会记录，即使尚未创建设备目录。

## 并发与兼容性

- 模板只解析一次，OS 命令和文件名在所有设备间共享；数组按倍增扩容，文件名用哈希表检查冲突。
- 工作线程默认 4 个，可设为 1–32 个。SSH 和 Telnet 共用线程池，同一设备复用一个连接，单台设备的命令始终串行。
- TCP/SSH/Telnet 使用非阻塞读写和 `select` 等待；按返回提示符判断完成，遇到常见 More 提示自动发送空格继续。输出短暂安静不会直接视为完成。
- SSH 标准输出与诊断流合并保存，避免设备将部分内容写入 stderr 时遗漏。
- 支持中文路径、Windows 长路径、IPv4、IPv6、自定义 SSH/Telnet 端口、SSH 密码认证与单密码 keyboard-interactive 认证，以及 Telnet 用户名/密码或仅密码认证。
- 单条命令接收上限为 32 MiB，达到上限会标记失败并保留部分结果；Excel 压缩文件及单个解压 XML 上限为 256 MiB。并发数越高，峰值内存和设备登录负载越高。

SSH 使用 libssh2 与 Windows WinCNG 加密后端，已测试 RSA、ECDSA 主机密钥。当前构建不支持仅提供 Ed25519/ChaCha20 的设备、SSH-1、串口、MFA、私钥登录、强制修改密码和需要交互式 enable 密码的流程。应确保账户直接进入可执行采集命令的 CLI。提示符或分页样式特殊的设备需要补充适配；模板中的命令应为查询命令。

SSH 首次连接会将主机密钥记录到所选输出目录下的 `_known_hosts`，之后同一地址密钥变化会拒绝连接。更换输出目录会产生新的首次信任记录；设备合法更换密钥时，应核对后更新对应记录。Telnet 不使用 SSH 主机密钥文件。

## 命令行

```powershell
.\netcollect-cli.exe --check .\C版采集模板.xlsx
.\netcollect-cli.exe --input .\C版采集模板.xlsx --output D:\采集结果 --workers 8
```

退出码：0 全部成功，1 存在设备失败，2 模板/文件错误，3 已停止。命令行支持 Ctrl+C 停止。

## 源码构建与测试

源码在 `csrc/`，采用 C11。固定依赖版本：libssh2 1.11.1、libtelnet 0.23、Expat 2.7.1、miniz 3.0.2；`bootstrap.ps1` 根据带 SHA-256 的清单下载到 `third_party/`，不将依赖源码纳入 Git，发行包附各自许可证。依赖官方资料：[libssh2](https://libssh2.org/)、[libtelnet](https://github.com/seanmiddleditch/libtelnet)、[Expat](https://github.com/libexpat/libexpat)、[miniz](https://github.com/richgel999/miniz)。

```powershell
.\setup.ps1
.\build.ps1
python -m pip install -r requirements-dev.txt
.\test.ps1 -Gui -Benchmark
.\package.ps1
python -B ctests/smoke_release.py
```

上面的 Python 仅用于准备构建工具、生成示例和启动本地模拟 SSH/Telnet 测试，程序运行不依赖 Python。测试脚本另需 `openpyxl`、`paramiko`，截图转 PNG 可选安装 `Pillow`。也可使用已配置的 MSVC 或 MinGW，通过 CMake 构建；本机已实际验证的是 Zig/Clang x64 Release 构建。

`ctests/` 中包含 C 核心测试、真实原生窗口及按钮测试、Python 本地 SSH/Telnet 模拟器和并发性能测试。测试结果见 `TEST_REPORT_C.md`，原始测试产物在 `test-output/`。本次没有连接实际生产设备。
